# Morse Code Audio Memory Challenge Game

## 概要
Web Audio APIでモールス信号を再生し、聞こえた文字・単語を入力する記憶ゲーム。

## 機能
- Web Audio APIによる正確なモールス信号音声生成（700Hz正弦波）
- 4つのゲームモード:
  1. **Letters**: A-Zの単一文字
  2. **Numbers**: 0-9の数字
  3. **Words**: 3〜4文字の英単語
  4. **Callsigns**: アマチュア無線コールサイン
- 速度設定: 5/10/15/20 WPM（PARIS標準タイミング）
- スコア・ストリーク・ベストストリーク・正答率
- 文字別正答率グリッド（色分け表示）
- モールス符号参照テーブル（折りたたみ）
- localStorageによるハイスコア保存

## 使い方
1. モードと速度を選択して "Start"
2. モールス信号を聞いて文字/単語を入力
3. "Play Again"ボタン（またはスペースキー）で再生
4. Enterキーで回答送信・次の問題へ
